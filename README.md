# ClaudeShell

**ClaudeShell** puts Claude Code in Docker, ready to go in a couple of clicks. Isolated container, firewall on by default, zero clutter on your host — just mount the project folders you need and get to work. Private, safe, clean.

## Requirements

[Docker Desktop](https://www.docker.com/products/docker-desktop) (macOS, Windows) or [Docker Engine](https://docs.docker.com/engine) (Linux) — **installed and running** before you start.

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/boboshko/claudeshell/main/install.sh | bash
```

## Usage

Go into the ClaudeShell folder:

```bash
cd claudeshell
```

Run the shell:

```bash
./start.sh
```
